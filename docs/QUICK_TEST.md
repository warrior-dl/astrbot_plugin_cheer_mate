# AI Friend 快速测试指南

## 问题修复记录

### ❌ 问题: 配置文件使用了不支持的 enum 类型
```
TypeError: 不受支持的配置类型 enum。
支持的类型有：['int', 'float', 'bool', 'string', 'text', 'list', 'object']
```

### ✅ 解决方案
1. 将 `reply_style` 的类型从 `enum` 改为 `string`
2. 在 `hint` 中说明可选值
3. 在代码中添加验证逻辑

---

### ❌ 问题 2: 中文指令无法注册
```
发送 /开启陪伴 后没有响应，插件没有注册任何行为
```

**原因**: AstrBot 不支持直接使用中文作为主指令名。

### ✅ 解决方案
1. 使用英文作为主指令名（如 `subscribe`）
2. 将中文作为别名（alias）
3. 用户可以使用 `/subscribe` 或 `/开启陪伴`

**修改示例**:
```python
# 错误写法
@filter.command("开启陪伴")

# 正确写法
@filter.command("subscribe", alias={"开启陪伴", "订阅"})
```

## 快速测试步骤

### 1. 部署插件

将插件文件夹复制到 AstrBot 插件目录：

```bash
# Windows
xcopy /E /I D:\ai-friend "你的AstrBot路径\data\plugins\astrbot_plugin_ai_friend"

# 或者直接在 AstrBot 插件目录中开发
```

### 2. 重启 AstrBot

重新启动 AstrBot，检查日志中是否有以下信息：

```
[AI Friend] 插件初始化完成
[AI Friend] 配置: 推送时间=22:00, 风格=balanced
[AI Friend] 已加载 0 个订阅用户
[AI Friend] 定时任务已启动，推送时间: 22:00
```

### 3. 测试订阅功能

在私聊中发送：
```
/开启陪伴
```

期望回复：
```
订阅成功！🌟

每天 22:00，我会主动问候你：
"今天感觉怎么样？有什么想分享的吗？"

如果不想收到推送，发送 /关闭陪伴 即可取消~
```

### 4. 测试手动触发

发送：
```
/夸夸我
```

期望回复：
```
今天做了什么想和我分享的吗？
```

然后回复：
```
就看了两页书
```

期望得到 AI 生成的夸夸回复（类似）：
```
太强了！在工作了一整天之后还能坚持看两页书，
这已经超过90%的人了。今天的进步条已经动了，安心去睡吧！

还有其他想分享的吗？
```

继续回复：
```
没了
```

期望回复：
```
好的！今天辛苦啦，晚安~ 🌙
```

### 5. 测试配置修改

在 WebUI 的插件配置页面：

1. 修改 `reply_style` 为 `enthusiastic`
2. 保存配置
3. 重载插件
4. 测试 `/夸夸我`，检查回复风格是否更加激励

## 可能的问题排查

### 问题 1: 插件加载失败

**检查**:
- 文件夹名称是否正确（必须是 `astrbot_plugin_ai_friend`）
- `main.py`、`metadata.yaml`、`_conf_schema.json` 是否存在
- 查看 AstrBot 日志中的详细错误信息

### 问题 2: 没有收到 AI 回复

**检查**:
- AstrBot 是否配置了 LLM（在设置中查看）
- 查看日志中是否有 LLM 调用错误
- 如果 LLM 失败，应该会返回降级回复（预设的温暖回复）

### 问题 3: Prompt 文件找不到

**检查**:
- `prompts/` 文件夹是否存在
- `balanced.txt`、`enthusiastic.txt`、`gentle.txt` 是否存在
- 如果文件不存在，会使用代码中的默认 Prompt

### 问题 4: 订阅数据丢失

**检查**:
- AstrBot 的数据目录是否有写入权限
- 查看日志中是否有存储相关错误
- 订阅数据存储在 AstrBot 的 KV 存储中，需要确保存储功能正常

## 调试技巧

### 查看日志

在 AstrBot 日志中搜索 `[AI Friend]`，可以看到：
- 插件初始化信息
- 订阅/取消订阅操作
- 定时任务触发
- LLM 调用结果
- 错误信息

### 手动触发定时任务测试

不想等到晚上 22:00？可以：

1. 在配置中将 `scheduled_time` 改为 5 分钟后的时间
2. 保存并重载插件
3. 订阅后等待 5 分钟
4. 检查是否收到推送
